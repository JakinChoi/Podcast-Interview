Host: Guest link maker

게스트 이름과 맞춤 질문만 입력하면 그 게스트 전용 링크가 만들어집니다. 나머지(가이드, 약관, 기본 질문)는 모든 게스트에게 동일합니다. / Enter a guest’s name and their own questions to get a link just for them. Everything else stays the same for all guests.

짧은 링크 / Short link

위에 입력한 이름·질문으로 index.html?guest=이름 같은 짧은 링크를 만듭니다. 질문을 고치고 다시 누르면 같은 링크가 그대로 유지됩니다. / Uses the name and questions above to make a short link like index.html?guest=name. Edit the questions and press again: the link stays the same.
GitHub 연결 설정 (한 번만) / GitHub connection (one-time)
토큰은 이 브라우저에만 저장되며 GitHub 외에는 어디로도 전송되지 않습니다. / The token stays in this browser and is only sent to GitHub.
GitHub 반영까지 1~2분 걸릴 수 있습니다. 링크를 보내기 전에 열어서 확인해 주세요. / It can take 1–2 minutes to go live. Open it to check before sending.
